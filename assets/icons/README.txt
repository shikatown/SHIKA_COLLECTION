UIアイコンは原則 CSS/SVG で自作しています。
ここにあるのは画像で用意したものだけです。
  coin.png    … SHIKA COIN（192px）。集めた記録の大きい表示用
  coin-sm.png … SHIKA COIN（48px）。アプリバーや一覧の小さい表示用

■ web/（表示用の軽い版）
  web/ に同じ名前の .webp があれば、アプリはそちらを先に読みます（元の PNG より数分の一の大きさ）。
  元の PNG を差し替えたら、web/ の同じ名前の .webp を作り直すか、消してください（消せば元の PNG が使われます）。
  消さずに PNG だけ差し替えると、古い絵が出ます。
