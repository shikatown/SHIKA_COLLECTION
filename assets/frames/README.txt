ジャンル共通の部品です。差し替えるとカード全体の見た目が変わります。

■ gourmet.png / spot.png / culture.png（台紙 1080×1350）
  外枠・背景・金の区切り線・所在地ピル・タイトル下の罫線を含みます。
  写真が入る部分は透過で、下に敷いた写真が窓から見えます。
  ボタン・ロゴ・カテゴリバッジは台紙に含みません（アプリ側で重ねます）。
  元にしたカード: グルメ=card-01 / スポット=card-41 / 文化=card-32

■ icon-gourmet.png / icon-spot.png / icon-culture.png（カテゴリアイコン 1254×1254）
  左上のバッジに入る絵。背景は透過。紺色のピルと文字はアプリ側で描きます。

■ logo.png（SHIKA COLLECTION ロゴ 1536×1024・透過）
  カード下部とホーム画面で使います。

位置は css/card-art.css の座標に合わせてあります。
差し替えるときは縦横比を大きく変えないでください。

■ web/（表示用の軽い版）
  web/ に同じ名前の .webp があれば、アプリはそちらを先に読みます（元の PNG より数分の一の大きさ）。
  元の PNG を差し替えたら、web/ の同じ名前の .webp を作り直すか、消してください（消せば元の PNG が使われます）。
  消さずに PNG だけ差し替えると、古い絵が出ます。
