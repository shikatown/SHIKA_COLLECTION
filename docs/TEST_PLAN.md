# TEST_PLAN — 公開前に確認する項目

実機（Android Chrome / iPhone Safari）とPC（Chrome / Edge）で確認する。

## 起動

- [ ] 起動画面のカードが、青緑色の仮の絵にならず最初から裏面の絵で出る
- [ ] 起動画面からホームに移るとき、ロゴがちらつかない／場所が動かない
- [ ] スキップを押してすぐ移っても同じ
- [ ] 通信を切った状態でも、読み込み済みの範囲で同じように起動する

## ガチャ

- [ ] 初回無料10連が自然に始まる
- [ ] 初回10連の10枚に重複がない
- [ ] 初回10連にグルメ・スポット・文化が最低1枚ずつ入る
- [ ] 通常ガチャで全カードが出うる（カテゴリ補正・未取得優遇がない）
- [ ] 1回=1コイン、10連=10コインちょうど減る
- [ ] コイン不足のとき、ボタンが押せず、増やし方が案内される
- [ ] 10連の途中でアプリを閉じても結果が残り、次回起動時に確認できる
- [ ] SKIPは1枚目表示後から押せる／押すと結果一覧へ飛ぶ
- [ ] 舞台をタップすると、その1枚の演出だけ最後まで飛ぶ
- [ ] 演出が 円舞→三分→合一→抜刀 の順に流れ、3つの束が上・左下・右下に寄る
- [ ] 三分のとき、3つの束が画面の上下いっぱいに開く（下が余らない）
- [ ] 引いたカテゴリに関わらず、3つの束の位置と所要時間が同じ
- [ ] 10連の2枚目以降が速すぎない（1枚目の半分ほどの速さ）
- [ ] 10連で、次のカードに行くまでに引いたカードを眺められる（2秒ほど）
- [ ] 抜刀後の光が、カード一覧や3Dビューアと同じ速さで走る
- [ ] 動きを減らす設定（prefers-reduced-motion）では演出せず結果だけ出る
- [ ] オフラインでもガチャが回り、結果が保存される
- [ ] カード画像が未キャッシュでも演出が破綻しない
- [ ] 演出が画面全体に広がり、ヘッダーとタブが隠れる
- [ ] 演出中は背後がスクロールしない／演出が終わると元に戻る
- [ ] 演出の途中でブラウザの戻るを押しても、スクロールが止まったままにならない
- [ ] NEW とカード名がカードと重ならない（縦長・横長のどちらでも）
- [ ] 1枚引きの結果でカードが中央に大きく出て、説明文がその下に離れて出る

## 写真の取り違え

- [ ] ガチャで引いたカードの写真と、カード一覧の同じカードの写真が一致する
- [ ] 本体を更新したあと、写真が別のカードのものにならない
- [ ] 設定の「写真を読み込み直す」で直る（カードとコインは消えない）
- [ ] カード番号を振り直したら、`data/version.json` の dataVersion も新しくする

## 画面の見出し

- [ ] 各画面で、アプリバーと同じ見出しが画面の中に繰り返されていない
- [ ] 「53 / 53 種類」「現地訪問 0 / 16 か所」などの一行は残っている

## 画面の行き来

- [ ] 一覧を下まで動かしてカードを開き、戻ると元の位置に戻る
- [ ] はじめて開く画面は、いちばん上から始まる
- [ ] 戻った直後に位置がずれて見えない（画像が入っても落ち着く）

## カード一覧・カード詳細

- [ ] 名前が長いカードと短いカードで、マスの高さが同じ
- [ ] カードを開いたとき、写真がちらつかずにだんだん鮮明になる
- [ ] カード詳細で左へ払うと次のカード、右へ払うと前のカードに移る
- [ ] 画面の左右の端（56pxほど）から払っても移らない（スマホの「戻る」が使える）
- [ ] カード詳細の左上にカード番号が出る
- [ ] 払っているあいだ、前後のカードが指について見える
- [ ] 途中でやめると、元の位置に戻る
- [ ] 払っても画面が横にスクロールしない
- [ ] 何度払っても1枚ずつ移る（まとめて飛ばない）
- [ ] 縦に動かしても移らない／払った指離しで3Dビューアが開かない
- [ ] カード一覧やほかの画面では、払っても何も起きない

- [ ] 未取得のカードが「番号入りの空き枠」で並ぶ（ジャンル別の色がつく）
- [ ] 名前の左にカード番号が出る
- [ ] ガチャのあとカード一覧を開くと、新しいカードが枠にはまる演出が出る
- [ ] 1枚ずつ、画面のまん中に大きく出てから回って枠にはまる
- [ ] 枠にはまるとき、カードの表が見えている（裏で止まらない）
- [ ] はまったカードに NEW が付き、画面を移るまで残る
- [ ] 暗いところをタップすると、残りがまとめて終わる
- [ ] はまったあと、そのカードだけ左から右へ光が走る（0.7秒ほど）
- [ ] 演出は見逃さない速さで、1枚ずつ順番にはまる
- [ ] 10連のとき、10枚すべてが画面に寄ってからはまる（最初の1枚だけではない）
- [ ] 演出の途中で自分で画面を動かすと、勝手に戻されなくなる
- [ ] 同じ一覧をもう一度開いても、演出は繰り返さない
- [ ] 「動きを減らす」設定では演出せず、すぐ並んだ状態で出る
- [ ] 現地訪問で手に入れたカードも、同じように枠にはまる
- [ ] カード詳細でカードが大きく出て、左右に少し余白がある
- [ ] カード詳細がスクロールしない（グルメ・スポット・文化のいずれも）
- [ ] カードに印刷されたボタンを押すと、地図や検索が別タブで開く
- [ ] カードのボタン以外を押すと3Dビューアが開く
- [ ] 文化カードにはボタンが無く、どこを押しても3Dビューアが開く
- [ ] ホーム画面に追加したときの名前が「シカコレ」になる
- [ ] カード詳細に説明文の段落が出ない（説明はカードの中だけ）
- [ ] 未取得のカード詳細では、空き枠が控えめな大きさで中央に出る

## 管理モード（公開前の点検用）

- [ ] 「その他」のバージョン表示を7回タップすると確認ダイアログが出る
- [ ] 入ると赤い帯が出続け、どの画面でも管理モード中だと分かる
- [ ] コインが0でもガチャが引ける（無料10連の消化フラグは立たない）
- [ ] 「カード点検」で全カードの状態と欠番・写真なし・長い文が分かる
- [ ] 「管理モードを終了する」で元に戻り、`#/admin` を直接開いても入れない
- [ ] **配布前に管理モードが切れている**

## まち巡り（地図）

- [ ] 2本指でつまんで広げると拡大、縮めると縮小する
- [ ] つまんだ中心の場所が、指を離しても画面の同じ位置にある
- [ ] 2本目の指だけ離したら、残った指でそのまま地図を動かせる
- [ ] ＋／− ボタンとホイールでも拡大縮小できる
- [ ] ピンや＋／− ボタンを押しても地図が動かない
- [ ] 大きいボタンが「チェックイン」になっている
- [ ] スポット行の「経路」を押すと Googleマップの経路検索が別タブで開く
- [ ] 「経路」を押しても、その行のカード詳細には飛ばない
- [ ] カード詳細の「現地に行く」欄はチェックインだけ（経路検索はカードのボタンが担う）

## データの手入れ

- [ ] `tools/excel-to-json.html` がアプリではなくツールとして開く（PWA導入後の端末でも）
- [ ] `tools/SHIKA_COLLECTION_カード管理.xlsx` が Excel で開ける
- [ ] その Excel をツールに読ませると 53 件・写真 52 枚になる
- [ ] カード番号が 001〜053 の連番で、一覧の並びと一致する

## 報酬

- [ ] デイリーは1日1回だけ
- [ ] 酒のアテは初取得時のみ（2枚目以降は付かない）
- [ ] かぶり5枚ごとに+1、6枚目以降は繰り越される
- [ ] 同カテゴリ5・10・15…種類で+2が自動付与される（受取ボタンがない）
- [ ] 複数のボーナスが同時発生しても、最後にまとめて1回だけ表示される

## 3Dカード

- [ ] ドラッグで自由回転し、裏面が見える
- [ ] 上下の傾きが±30°程度で止まる
- [ ] 離すと減衰して止まり、高速で回り続けない
- [ ] ダブルタップで正面へ戻る
- [ ] ×・背景タップで閉じる／スワイプでは閉じない
- [ ] 閲覧中は振動しない
- [ ] 取得済みカードだけ「前／次」で移動できる
- [ ] 初回だけ操作案内が出て、以降は出ない
- [ ] 光が左から右へ0.7秒ほどで走り、少し間を置いてまた左から走る
- [ ] 置いてあるときのカードの真ん中に、光のもやが残らない
- [ ] しっかり傾けると、面に沿って光沢が動く
- [ ] カードが大きく出る／低い画面でも「前／次」や案内文と重ならない

## GPS

- [ ] 自動で位置情報を要求しない（ガチャだけの利用者には一切求めない）
- [ ] [現在地を確認]を押したときだけ許可を求める
- [ ] 許可した場合／拒否した場合それぞれで文言が正しい
- [ ] 精度が基準未満のとき判定せず、案内を出す
- [ ] 範囲外のとき「まだ範囲外」の案内が出る
- [ ] 範囲内の複数スポットが1回の確認でまとめてチェックインされる
- [ ] 初訪問 +3、未取得ならカードも確定取得される
- [ ] 同日中の再訪はボーナスなし、翌日の再訪で +1
- [ ] 町初訪問 +5 が1回だけ加算され、スポット初訪問と加算される
- [ ] オフラインでもチェックインできる
- [ ] チェックイン後、近い未訪問が最大3件出る

## データ

- [ ] cards.json にカードを追加 → 起動時に「新しいカードが◯種類」と1回だけ出る
- [ ] cards.json の説明文を修正 → 取得済み状態が消えない
- [ ] カードを非公開にする → 一覧から消えるが取得記録は残る
- [ ] 再公開すると取得済みで戻る
- [ ] 欠番IDがあっても動く
- [ ] バックアップを保存 → リセット → 復元で元に戻る
- [ ] 壊れたJSONを復元しようとすると、はじかれる
- [ ] リセットは二段階確認で、初回無料10連からやり直せる

## PWA / オフライン

- [ ] 初回読み込み後、機内モードでもホーム・コレクションが開く
- [ ] 2回目以降の起動が速い
- [ ] `service-worker.js` の `APP_VERSION` を上げると更新通知が出る
- [ ] 「更新する」を押したときだけ再読み込みされる
- [ ] ホーム画面に追加してアプリ風に起動する

## プライバシー

- [ ] GPS座標がどこにも保存されていない（DevTools → Application → Local Storage で確認）
- [ ] 外部への送信が地図タイルと同一ドメインのファイル取得だけである（DevTools → Network で確認）
- [ ] 解析タグ・外部フォント・アイコンCDNの読み込みがない

## 表示

- [ ] スマホ縦持ちで崩れない
- [ ] PC・タブレットで中央にスマホ幅相当が出る
- [ ] 横持ちでも操作できる
- [ ] カード画像が未設定でも一覧・詳細・3Dが破綻しない
- [ ] 長い名前・長い説明文で崩れない（例：日本遺産　北前船寄港地福浦港）
