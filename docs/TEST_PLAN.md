実機（Android Chrome / iPhone Safari）とPC（Chrome / Edge）で確認する。

## 起動

- [ ] 起動画面のカードが、青緑色の仮の絵にならず最初から裏面の絵で出る
- [ ] 起動画面からホームに移るとき、ロゴがちらつかない／場所が動かない
- [ ] スキップを押してすぐ移っても同じ
- [ ] 通信を切った状態でも、読み込み済みの範囲で同じように起動する

## ガチャ

- [ ] 初回無料10連が自然に始まる
- [ ] 初回10連の10枚に重複がない
- [ ] 初回10連にグルメ・スポット・文化が最低1枚ずつ入る
- [ ] 通常ガチャで全カードが出うる（カテゴリ補正・未取得優遇がない）
- [ ] 1回=1コイン、10連=10コインちょうど減る
- [ ] コイン不足のとき、ボタンが押せず、増やし方が案内される
- [ ] 10連の途中でアプリを閉じても結果が残り、次回起動時に確認できる
- [ ] 演出の途中でスマホの戻るを押すと、演出が止まる
- [ ] 戻った先の画面に、ガチャの結果が紛れ込まない
- [ ] ガチャを開き直すと、すぐ結果が出る
- [ ] 引いたときの音が、新しいカードでもそうでなくても同じ
- [ ] 枠にはまる瞬間に「パチーン」と鳴る
- [ ] SKIPは1枚目表示後から押せる／押すと結果一覧へ飛ぶ
- [ ] 舞台をタップすると、その1枚の演出だけ最後まで飛ぶ
- [ ] 演出が 円舞→三分→合一→抜刀 の順に流れ、3つの束が上・左下・右下に寄る
- [ ] 三分のとき、3つの束が画面の上下いっぱいに開く（下が余らない）
- [ ] 引いたカテゴリに関わらず、3つの束の位置と所要時間が同じ
- [ ] 10連の2枚目以降が速すぎない（1枚目の半分ほどの速さ）
- [ ] 10連で、次のカードに行くまでに引いたカードを眺められる（2秒ほど）
- [ ] 抜刀後の光が、カード一覧や3Dビューアと同じ速さで走る
- [ ] 動きを減らす設定（prefers-reduced-motion）では演出せず結果だけ出る
- [ ] オフラインでもガチャが回り、結果が保存される
- [ ] カード画像が未キャッシュでも演出が破綻しない
- [ ] 演出が画面全体に広がり、ヘッダーとタブが隠れる
- [ ] 演出中は背後がスクロールしない／演出が終わると元に戻る
- [ ] 演出の途中でブラウザの戻るを押しても、スクロールが止まったままにならない
- [ ] NEW とカード名がカードと重ならない（縦長・横長のどちらでも）
- [ ] 1枚引きの結果でカードが中央に大きく出て、説明文がその下に離れて出る
