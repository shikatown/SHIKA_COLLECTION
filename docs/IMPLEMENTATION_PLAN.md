## 仕様書との差分

1. **`js/analytics.js` は作っていない。**
   仕様書§35の推奨構成にファイル名があるが、§3・§32・§40 でアクセス解析・行動追跡を禁止しているため、
   置くと誤解のもとになると判断した。解析コードは1行も入っていない。

2. **`js/ui.js` と `js/sound.js` を追加した。**
   推奨構成にない2ファイル。画面部品と効果音生成の共通処理をまとめたもので、機能追加ではない。

3. **地図に「チェックイン対象外」の場所も表示している。**
   仕様書§17ではGPS対象フラグで対象を決めるとあり、それは守っている（チェックインできるのはフラグ○のみ）。
   一方で座標を持つカード（松尾神社・高爪山・福浦港など）が地図から消えると案内として不便なため、
   灰色のピンで参考表示し、チェックイン対象と区別した。Excel で「GPS対象」に○を入れれば対象になる。

4. **カテゴリ「文化」は現在4種類。** カテゴリ5種類ごとの報酬（+2）は文化では発生しない。
   カードを1種類追加すると発生するようになる。

5. **カード032「さくら貝」のカテゴリはカード画像から「文化」と確定した。**
   Excel上は「アプリカテゴリ」が空欄だが、支給されたカード画像 `card-32.png` に「文化」と印刷されている。
   推測ではなく現物の記載に従い、`culture` として公開している。
   **ただしExcelは空欄のままなので、次に変換ツールを使うと再び非公開になる。**
   Excelの032行に「文化」を入れておくこと。

6. **カードは1枚絵をやめ、部品から組み立てる方式にした（v1.1）。**
   文言の修正のたびに画像を作り直す運用を避けるための変更。
   ジャンル共通の意匠は台紙画像にまとめ、カードごとに変わるものはデータから描く。

   | 層 | 中身 | 出どころ |
   |---|---|---|
   | ① 写真 | 産品・風景 | `assets/photos/`（Excelのセル内画像） |
   | ② 台紙 | 外枠・背景・区切り線・所在地ピル・罫線 | `assets/frames/<ジャンル>.png` |
   | ③ バッジ | 紺のピル＋アイコン＋カテゴリ名 | `assets/frames/icon-<ジャンル>.png` ＋ 描画 |
   | ④⑤⑥ | 番号・名前・説明 | `cards.json` |
   | ⑦ ボタン | 白い角丸ボタン | `cards.json` の cardButton / `config.json` の cardButtons |
   | ⑧ ロゴ | SHIKA COLLECTION | `assets/frames/logo.png` |

   台紙は現行カードから作った。写真部分・名前・説明の帯・ボタン・ロゴを消し、
   ジャンル共通の意匠だけを残してある。
   元になったカード: グルメ=card-01 / スポット=card-41 / 文化=card-32。
   実測した設計座標（1080×1350）は `css/card-art.css` の冒頭に記録してある。

   組み立てた結果を元カードと画素で突き合わせた実測値（card-01）:
   ロゴ x428–648 y1122–1258（元 x428–651 y1124–1260）、
   ボタン x96–983 y1048–1109（元 x96–984 y1048–1110）。

7. **カードの文字はシステムフォントで描く。**
   元のカードは専用フォントで焼かれていたが、Webフォントは使わない方針（§40）のため、
   端末標準のゴシックで表示する。太さ・字幅がわずかに異なる。

8. **カードに載る説明文が長いカードが10件ある。**
   元のカード画像には、Excelの説明文より短く書き直された文が焼き込まれていた。
   その短い文は画像の中にしか無く、取り出せない。
   現在は `description` を3行で切って表示している。Excelに「カード説明文」列を作って
   短い文を入れると、そちらが優先される。
   該当: 029 / 032 / 036 / 037 / 038 / 043 / 044 / 045 / 051 / 052。

9. **写真はExcelのセル内画像から取り出した。**
   「詳細写真１」列に貼られた画像がカードの元写真だった。52枚をカードIDに紐づけて抽出。
   051（西海祭り）だけ写真が無く、元のカードでも「写真準備中」になっていた。
   変換ツールにも同じ抽出機能を入れてあるので、Excelを直せば写真も更新できる。

   参考: 一度カード画像をWebP(q0.9)へ変換したが、画質優先の指示で取りやめた。
   原寸1080pxで PSNR 32.5〜33.9dB、品質を上げても色差の間引き(4:2:0)で頭打ちになる。

10. **カードの縦横比は 4:5（1080×1350）。** 当初 63:88 を想定していたが、実物に合わせて変更した。

11. **カード画像側のカテゴリとExcelのカテゴリを全51枚で照合した。**
    カード下段の帯の色（グルメ=茶 / スポット=緑 / 文化=紫）を機械的に読み取って突き合わせ、
    032以外はすべて一致することを確認済み。

## 実装判断ルール（仕様書§39の適用）

迷ったときは次の順で優先した。
個人情報を集めない → 無料で運用できる → カードデザインを壊さない → スマホで扱いやすい →
外部依存を減らす → オフラインで使える → Excelで運用変更できる → 確認を増やさない →
ガチャと観光情報を分離 → 不明な観光情報を推測しない。

具体例：
- 地図ライブラリ（Leaflet等）を使わず、タイル表示を自前で書いた（外部依存とオフライン対応のため）
- Excel読み込みも外部ライブラリを使わず、ブラウザ標準の `DecompressionStream` でzipを展開している
- 効果音は生成、アイコンはSVG、フォントは端末標準

12. **裏面・ロゴ・カテゴリアイコンは支給パーツに差し替えた（v1.2）。**
    - 裏面 `assets/cards/_back.png`（1122×1402）… ガチャ演出と3Dビューアの裏面
    - ロゴ `assets/frames/logo.png`（1536×1024 透過）… カード下部とホーム画面
    - アイコン `assets/frames/icon-<ジャンル>.png`（1254×1254 透過）… カテゴリバッジ
    - PWAアイコンも裏面デザインから作り直した（仕様§31）
    いずれも支給ファイルを無変換で同梱している。可逆再圧縮も試したが逆に大きくなったため見送った。

13. **カード下部のボタンを台紙から外し、文言をデータで決めるようにした。**
    「ほかの文言が入るかもしれない」ため。優先順は カード個別（Excel「カードボタン文言」）→
    ジャンル既定（`config.json` の `cardButtons`）→ 文言が無ければボタンを出さない。
    文字色は元カードから実測した（グルメ #4a2314 / スポット #0c3336）。

14. **ガチャ演出を作り直した（v1.3）。**
    4拍構成、全4800ms。毎フレーム transform を書き換える方式（rAF）で `js/gacha-anim.js` に分離した。

    | 拍 | 時間 | 内容 |
    |---|---|---|
    | 序 | 0–400ms | 9枚が重なった束が中央で沈む |
    | 一 円舞 | 400–1700ms | 束がほどけ、傾いた楕円（rotateX 64°）を等弧長で回る |
    | 二 三分 | 1700–2400ms | 3枚ずつ3つの束に寄る。2020/2180/2340ms の3拍でジャンル色に染まる |
    | 三 合一 | 2400–3120ms | 3つの束が渦を巻いて中心で1つになる。着弾で閃光・衝撃波・カメラの揺れ |
    | 四 抜刀 | 3120–3800ms | 1枚が抜けて540°翻り表になる。面が替わるのは3520ms |
    | 結 | 3800–4800ms | 金粉が降り、カード名が4000msにせり上がる |

    3つの束は グルメ=上 / スポット=左下 / 文化=右下 に固定。引いたカテゴリで位置は変えない
    （位置が変わると抜刀前に結果が読めてしまう）。所要時間も3カテゴリ同一で、
    変えるのは光の色と粒子の性格だけ（レアリティを作らない方針）。

    10連は 1枚目が全4800ms、2〜9枚目は円舞と三分を省いて合一の直前から2.4倍速（約860ms）、
    最後の1枚は余韻まで見せる。全体で約15秒。SKIPは1枚目の表示後（約4.8秒）から押せる。
    舞台をタップすると、その1枚の演出だけ最後まで飛ぶ。
    `prefers-reduced-motion` では動かさず最終状態だけ見せる。

15. **カード一覧の重さを直した（v1.4）。**
    53枚を並べる一覧で、原寸（写真1〜3MB・台紙330KB・アイコン1.3MB・ロゴ1.8MB）を
    そのまま横110pxに縮めて描いていたため、描画が数秒かかっていた。

    | 対策 | 効果 |
    |---|---|
    | `assets/photos/thumb/`（幅360px・JPEG）を一覧で使う | 写真 34MB → 1.2MB |
    | `assets/frames/thumb/`（台紙384px・アイコン128px・ロゴ320px） | 部品 6.8MB → 417KB |
    | 画像すべてに `loading="lazy"` | 画面外は読み込まない（53枚中30枚程度で済む） |
    | `.cell` に `content-visibility:auto` | 画面外のカードは描画しない |
    | `.card--img` の `container-type` を外す | サイズコンテナが半分に |

    縮小版が無ければ原寸に切り替わるので、`thumb/` を消しても表示は欠けない。
    変換ツールの「写真を書き出す」も、原寸と一緒に `thumb/` を作るようにした。

    注意: `contain-intrinsic-size` に1つの長さだけ書くと**幅にも効いて**3列目がはみ出す。
    `contain-intrinsic-height` で高さだけ指定すること。

16. **カード一覧で説明文が消えていたのを直した（v1.4）。**
    小さい表示のときに説明文・ボタン・カテゴリ名を隠すコンテナクエリを入れていたが、
    カードが1枚の絵として欠けて見えるため取りやめた。文字は cqw なので比率どおりに縮む。

17. **3Dビューアの×ボタンが押せなかったのを直した（v1.4）。**
    カード名の帯（`.viewer3d__caption`）が画面幅いっぱいの要素で、DOM順があとのため
    ×ボタンの上に重なってタップを奪っていた。帯を左右56pxだけ内側に寄せ、
    `pointer-events:none` を付け、ボタンに `z-index` を与えた。
    同じ理由で `.viewer3d__hint` にも `pointer-events:none` を付けた。

18. **カード詳細のカード画像も縮小版を使うようにした（v1.4）。**
    詳細画面のカードは表示幅が約150pxしかないのに原寸写真を読んでいたため、
    開いた直後に写真だけ遅れて出ていた。一覧と同じ `small` 指定にして、
    未取得カードの枠（`lockedCard`）にも縮小版が渡るようにした。
    大きく見せる3Dビューアは今までどおり原寸を読む。

19. **小さい表示のときの説明文が3行目を覗かせていたのを直した（v1.4）。**
    2行に切る指定だけでは枠の高さが3行分のままだった。高さも2行分に揃えた。

20. **ガチャ演出を画面全体にした（v1.5）。**
    `.gachastage` を `position:fixed; inset:0` にして、ヘッダーとタブの上にかぶせる。
    演出の座標は `js/gacha-anim.js` が毎フレーム舞台の実寸から計算するので、
    大きさを変えても中身は自動で追従する。抜き出すカードは `min(74vw,46vh,340px)`。
    幅と高さの両方で頭打ちにしないと、横長の画面でカードが縦にはみ出す。
    演出中は `body.is-drawing` で背後のスクロールを止め、
    途中で画面を離れたときのために `hashchange` でも必ず外す。

21. **NEW とカード名を演出面の中に移した（v1.5）。**
    以前はカード名を舞台の外（`#view` の下）に置いていたので、
    全画面にすると隠れてしまう。`.gacha__caption` にまとめて画面下寄りに固定した。
    カードの大きさが変わっても重ならない。

22. **1枚引きの結果を中央ぞろえで大きくした（v1.5）。**
    2列グリッドに1枚だけ入れていたため左上に寄っていた。`.result__solo` を使い、
    カード幅 `min(66vw,260px)` で中央に置き、説明文は `--low` で下げる。
    この1枚だけは縮小版ではなく原寸を読む（大きく出すのでぼやけさせない）。

23. **カード番号のピルをジャンルバッジとそろえた（v1.5）。**
    番号は固定幅で余白が無く、文字がピルからあふれて見えていた。
    高さ・上端をバッジと同じにし（4.815% = 6.019cqw）、幅は中身にあわせ、
    右端 x=993 を固定した。文字数が増えても外に出ない。

24. **3Dビューアのカードを大きくした（v1.5）。**
    `min(74vw,300px)` から `min(88vw,54vh,420px)` に。大きさは `--c3w` の1か所で決め、
    影の位置（CSSとJSの両方）も同じ変数を見る。

25. **カード詳細をカード中心の並びにした（v1.6）。**
    カードを画面の端まで（`.view` の左右余白を打ち消して）大きく出し、
    ジャンル・名前・ボタンはその下に置く。説明文はカードに印刷されているので、
    本文からは外した。カードが大きいので写真も原寸を読む。
    未取得のときだけは空き枠なので、幅58%にとどめて中央に置く。

26. **未取得カードを「番号を振った空き枠」にした（v1.6）。**
    以前はカードの絵を暗くして出していたが、アルバムの台紙のように
    番号が先に並んでいるほうが、何番が揃っていないか分かる。
    `lockedCard()` が `.card--slot` を返す。色はジャンル別（`--slot-c`）。

27. **新しいカードが枠にはまる演出を入れた（v1.6）。**
    取得したカードの番号を `unseenCardIds` に控えておき、次にカード一覧を開いたとき
    空き枠の上にカードが落ちてはまる。はまった枠は一度だけ光る。
    見せ終わったら控えを空にするので、次に開いたときは静かになる。
    「動きを減らす」設定のときは演出せず、控えだけ消す。
    控えを積むのは `rewards.js`（ガチャ）と `geo.js`（現地訪問）の2か所。

28. **一覧の名前にカード番号を添えた（v1.6）。**
    `#01 甘えび` の形。空き枠の番号と並びがそろう。

29. **`el()` がカスタムプロパティを設定できるようにした（v1.6）。**
    `Object.assign(style, {'--i':1})` では CSS 変数は入らない。
    `--` で始まるキーは `setProperty` に回す。演出の順番待ちがこれで効く。

30. **アプリ名を SHIKA COLLECTION にした（v1.7）。**
    `index.html` のタイトルとアプリバー、`js/app.js` の既定タイトル、
    `manifest.webmanifest` の `name`／`short_name`、README の見出し。
    `data/config.json` の `townName`（志賀町）はマップ検索に使う語なので変えない。

31. **枠にはまる演出をゆっくりにし、光を走らせた（v1.7）。**
    0.44秒では気づけなかった。落ちて止まるまでを0.92秒に伸ばし、
    はまったあとに、そのカードだけ左から右へ光が走る（`.cell__drop::after`）。
    1枚ずつ順番にはまる（5枚以下は0.52秒間隔、それ以上は0.36秒間隔）。
    手ごたえ（振動）は「はまった瞬間」に返す。

32. **ガチャ演出の中心を画面のまん中にした（v1.7）。**
    三分のとき3つの束が上半分に固まり、下が余っていた。
    中心を高さの44%から50%に下げ、束の振り分けも縦 ±0.33/0.225H、
    横 ±0.255W に広げた。周回の楕円も縦半径を0.215Hから0.30Hにした。
    札・光の輪・光条の大きさも画面の大きさから決めるようにした。
    **注意**: 中心の値は `js/gacha-anim.js` の `cy()` と
    `css/animations.css` の `top:50%`（カード・紋・光の輪・光条・閃光）の
    両方にある。片方だけ変えると中心がずれる。

33. **カード詳細のカードを端から少し離した（v1.7）。**
    画面の端まで届かせていたが、左右に10pxだけ余白を残す（`margin:0 -6px`）。
    角の丸みも戻した。

34. **ホーム画面の短縮名を「シカコレ」にした（v1.8）。**
    `manifest.webmanifest` の `short_name`。アイコンの下は端末が12文字ほどで
    切るので、正式名（SHIKA COLLECTION）とは別に短いものを置く。

35. **カードに印刷されたボタンを本物のリンクにした（v1.8）。**
    カードの絵はそのまま、`.cardart__btn` の上に透明な `<a>`（`.cardart__hit`）を重ねる。
    行き先は `cardActionUrl()` が決める：スポットは座標の地図、

    - ゆっくり見せたいので、回転の長さを 0.86秒 から 1.5秒（10連は1.15秒）にした。
    確認: 面の移り変わりが 裏→表→裏→表 の順で、
    入れ替わるのは横幅がほぼ0のとき。どの瞬間も左右反転していない。

73. **起動直後にカード一覧から始めたとき、演出が起動画面の裏で進んでいたのを直した（v1.18.1）。**
    v1.17 で「起動画面が出ているうちにホームを組み立てる」ようにしたため、
    カード一覧から始まると起動画面の裏で演出が走り、見えないまま終わっていた。
    起動画面が消えるまで待ってから始める。

74. **画面まわりの書体を、ロゴに合う丸い書体にした（v1.19）。**
    外部フォントは使わない決まりなので、端末に入っているものから選ぶ。
    `--font-ui` に丸ゴシック（ヒラギノ丸ゴ、sans-serif-rounded ほか）を並べ、
    無い端末ではこれまでどおりの書体に落ちる。
    **カードに印刷する文字（`--font`）は変えていない。** 読みやすさを優先する場所なので、
    `css/card-art.css` はこれまでの書体のまま。
    あわせて、角の丸みを14pxから16pxに、ボタンと見出しを少し太くした。
    タブはアイコンを丸い座ぶとんに乗せ、選んでいるものだけ色づくようにした。
