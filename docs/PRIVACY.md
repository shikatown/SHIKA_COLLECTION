# PRIVACY — プライバシーの扱い

原則として個人情報を収集しない。アプリ内の表示（設定 → プライバシーについて）と同じ内容。

## 収集・保存・送信しないもの

- 氏名 / 住所 / 電話番号 / メールアドレス（入力欄そのものがない）
- ユーザーアカウント
- GPS現在地の緯度経度
- カード取得履歴のサーバー送信
- チェックイン結果のサーバー送信
- SHIKA COIN 残高のサーバー送信
- 「気になる」情報のサーバー送信

アクセス解析・行動分析・ユーザー追跡は行わない。Google Analytics 等の解析タグは導入しない。

## 位置情報

- 自動取得はしない。`[現在地を確認]` を押したときだけ `navigator.geolocation` を呼ぶ
- 取得した緯度経度は JavaScript のメモリ変数（`geo.js` の `fix`）にのみ置く
- 判定後に保存するのは次の3つだけ
  - `spotId`（どのスポットか）
  - 初訪問済みかどうか、初訪問日時
  - 最終訪問日（日付のみ。再訪ボーナスの1日1回判定に使う）
- ガチャだけで遊ぶ利用者には、位置情報の許可を一度も求めない

## 端末内に残るもの

`localStorage` のキー `shika-gacha:state`（詳細は STATE_SCHEMA.md）。
ブラウザのデータを削除すると消える。復元手段としてバックアップファイルの保存を用意している。

Service Worker の Cache Storage に、アプリ本体・カード画像・地図タイルがキャッシュされる。
ここに個人を識別する情報は入らない。

## 外部への通信

| 宛先 | 内容 | タイミング |
|---|---|---|
| 配信元（GitHub Pages） | HTML/CSS/JS、cards.json、画像 | 起動時・表示時 |
| `tile.openstreetmap.org` | OpenStreetMap の地図タイル | まち巡り画面を開いたとき |
| `www.google.com/maps` | 検索語または緯度経度を含むURL | 利用者がリンクを押したときだけ |

Google Maps へのリンクには、利用者の現在地は含めない（スポットの座標または検索語のみ）。

## 実装上の確認ポイント

- `geo.js` の `fix` を localStorage へ書き出していないこと
- `visits` に緯度経度を混ぜていないこと
- バックアップファイル（`backup.js`）に座標が含まれないこと
- `fetch` の宛先が上表以外に増えていないこと
