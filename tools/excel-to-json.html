アイテム.xlsx → cards.json / 写真 書き出しツール

ブラウザの中だけで変換します。ファイルはどこにも送信されません。インストールも不要です。
Excelを直せばカードの文言・写真・リンクがすべて更新できます。画像を作り直す必要はありません。

使い方

  1. Excel（アイテム_志賀町ガチャ管理列追加.xlsx）を下の枠にドロップする
  2. 「cards.json を保存」を押す → リポジトリの data/cards.json に上書き
  3. 写真を入れ替えた場合は「写真を書き出す」も押す → assets/photos/ に展開して上書き （一覧用の小さい写真 thumb/ も一緒に作られます）
xlsx ファイルをドラッグ＆ドロップ またはクリックしてファイルを選ぶ

シートを選ぶ

「カードID」の見出しがある行を自動で探します。

変換結果


    

      photos.zip を展開して assets/photos/ に入れてください。ファイル名はカードIDになります。

      中の thumb/ フォルダは一覧表示用の小さい写真です。これも一緒に入れてください
      （無くても動きますが、カード一覧が重くなります）。
    

  


  

    
カード写真のフォルダ（Excelに写真を貼らない場合）

    

      Excelの「写真ファイル名」列にファイル名を書き、その写真が入ったフォルダをここで選びます。

      「写真ファイル名」が空の行は、カードID と同じ名前のファイル（例：001.jpeg）を探します。

      Excelのセルに写真を貼っている場合は、こちらを選ばなくてもかまいません。
    

    
    

  


  

    
完成カード画像で上書きする（任意）

    

      通常は不要です。カードは写真と文字から組み立てられます。

      1枚絵の完成カードを使いたい場合だけ、そのフォルダを選ぶと「カード画像」として割り当てます。
    

    
    

  


  

    
列の対応

    

      
Excelの列名cards.json

      
カードIDid（永続。再利用しない）

      
アプリカテゴリcategory（グルメ→gourmet / スポット→spot / 文化→culture）

      
公開published（○ のみ公開）

      
名前name … カードの見出し

      
詳細写真１ のセル内画像photo … カードの写真（写真の書き出しで取り出せます）

      
写真ファイル名photo … 上のフォルダから同じ名前の写真を取り込む（セル内画像より優先）

      
カード説明文cardText … カードに載せる短い文（3行まで。空なら説明文を使う）

      
カードボタン文言cardButton … カード下部のボタン文字（空ならジャンル既定。config.json で設定）

      
説明文description … 詳細画面の本文

      
緯度経度gps.lat, gps.lng（「37.12345,136.6789」の形式）

      
酒のアテsakeSnack（○ のみ。自動推論はしない）

      
GPS対象 / GPS判定半径(m)gps.enabled / gps.radius

      
購入検索 / Maps検索ワードpurchase.enabled / purchase.searchWord

      
店舗1〜3 名称・MapsURLpurchase.shops[]

      
外部リンク種別 / URLexternalLinks[]

      
旬・開催時期 / 見どころ・楽しみ方season / highlight

      
カード画像cardImage（完成画像で上書きする場合のみ）

      
アプリ備考（出力しません。管理者用）

    

  


  

    このツールは xlsx を自前で読みます（外部ライブラリを同梱していません）。

    Chrome / Edge / Safari 16.4 以降で動作します。
